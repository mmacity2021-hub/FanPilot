# Manifeste Flathub

à Flathub. Il gèlera les sources (tag + commit git) et référencera
`cargo-sources.json`.

En attendant, le manifeste fonctionnel local reste dans `flatpak-src/`.

Voir [docs/flathub.md](../docs/flathub.md).
