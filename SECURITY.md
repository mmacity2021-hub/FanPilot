# Politique de sécurité

## Versions supportées

| Version | Supportée |
|---|---|
| 0.1.x | ✅ |

## Signaler une vulnérabilité

**Ne pas ouvrir d'issue publique.**

Envoyer un mail à `security@fanpilot.example` avec description, étapes de
reproduction et impact estimé.

Réponse sous 72 h. Divulgation coordonnée après correctif.

## Périmètre

- Code Rust (`src-tauri/`)
- Frontend (`src/`)
- Manifeste Flatpak et permissions
- Chaîne de build CI
