# Gouvernance

## Rôles

- **Mainteneurs** : revue, merge, releases
- **Contributeurs** : PR, issues, docs

## Décisions

Consensus entre mainteneurs. En cas de blocage : vote à la majorité simple.
Les changements majeurs nécessitent un accord d'au moins deux mainteneurs.

## Devenir mainteneur

Contribution régulière sur ≥ 3 mois + nomination par un mainteneur existant.
