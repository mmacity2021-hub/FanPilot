# Démarrer en 5 minutes

## Installer

    flatpak install flathub com.fanpilot.app
    flatpak run com.fanpilot.app

## Builder depuis les sources

    git clone https://github.com/mmacity2021-hub/FanPilot.git
    cd FanPilot
    ./scripts/build-flatpak.sh
    ./scripts/run.sh

Voir [build.md](build.md).
