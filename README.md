# FanPilot

> Contrôle des ventilateurs pour Mac sous Linux.

Interface Tauri (Rust + WebView), empaquetée en Flatpak.

## Installation

    flatpak install flathub com.fanpilot.app

## Build depuis les sources

    ./scripts/build-flatpak.sh
    ./scripts/run.sh
